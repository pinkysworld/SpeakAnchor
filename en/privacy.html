The app “SpeakAnchor”

  • No data sent to us: no user account, no ads, no analytics or crash reports.
  • Local storage: scripts, earlier versions and settings stay on your device, in the folder %LOCALAPPDATA%\SpeakAnchor. Imported files are read locally only. A technical startup log without script text is kept in the Windows temp folder.
  • Phone remote (optional): the app starts a small web server on your local network only when you turn the remote on. It accepts requests only from the local network with the PIN shown, transfers no scripts and sends nothing to the internet.
  • Export: data leaves your PC only if you export it yourself or save it in a synced folder. The provider's terms then apply.

Microsoft Store

Purchase, download, licensing and updates are handled by the Microsoft Store. Microsoft processes data under its own responsibility according to the Microsoft Privacy Statement. We only receive aggregated, anonymous sales and install statistics.
